# Definition of Done

A story is done when all of these are true:

- [ ] Every acceptance criterion on the issue passes.
- [ ] Logic has tests, written red → green; full suite passes.
- [ ] Commits are atomic, Conventional Commits, and reference the issue; the last one says `Closes #N`.
- [ ] Copy follows [brand.md](brand.md) voice; any persuasion element follows [persuasion.md](persuasion.md), with no fake data.
- [ ] Works at phone width (375px) and desktop; keyboard usable; text contrast meets WCAG AA.
- [ ] Type check, lint and build pass.
- [ ] Deployed preview checked in a real browser.
